## Client Composition

`JamUnity/Assets/M1`의 `ClientRoot`는 native runtime, world presentation, input, social, character content UI를 조립한다. Native event는 network, world, actor, social sink에 각각 연결되고 매 frame `NativeManager.Process()`와 `WorldManager.Tick()`으로 처리된다.

## Login, Character Selection, and Entry

`ClientRoot.Login()`은 UI에서 받은 login ID와 password로 native runtime을 시작한다. Network state가 `Ready`이고 bootstrap kind가 `Fresh`이면 character list request를 한 번 제출한다. `CharacterSelectUI`는 목록을 표시하고 선택된 character ID로 select request를 보낸다.

```text
Login UI -> ClientRoot.Login
    -> network Ready (Fresh)
    -> character list
    -> CharacterSelectUI selection
    -> character select success
    -> world entry request
```

select response가 성공하면 `ClientRoot`가 world entry request를 제출한다. main world가 활성화되고 local controlled actor가 존재할 때만 character control과 chat UI가 활성화된다.

## World Presentation and Input

`WorldManager`는 native runtime의 main world ref를 보고 active world presentation을 교체한다. actor frame은 actor archetype과 control ownership에 맞는 presentation으로 표현하며, local controlled actor에는 configured smoothing을 적용한다.

입력은 `InputManager`가 profile 조합에 맞춰 `CharacterControlIntent`를 만들고, `ClientRoot`가 native runtime에 제출한다. chat text input이 focus를 가지면 movement input은 억제된다. local controlled actor가 사라지거나 main world가 바뀌면 input 상태를 reset하고 control을 비활성화한다.

| Area | Current behavior |
| --- | --- |
| Camera | configured profile을 적용하며 third-person에서는 orbit yaw/pitch를 반영 |
| Movement | enabled local controlled actor에 대해서만 control intent 전송 |
| World transition | main world presentation과 chat world label을 갱신 |
| AOI debug | focus가 없을 때 `V` key로 camera AOI debug view 토글 |

## Chat UI

`ChatUI`는 Global, 현재 World(Group), Direct channel을 제공한다. 일반 text는 현재 channel로 전송하며, command는 `/a`, `/g`, `/w <characterName> <message>`, `/dm <characterName> <message>`를 지원한다.

수신 text는 social payload decode가 성공할 때만 history에 추가된다. Direct message는 character name별 tab을 만들며, World channel은 현재 main world ID와 동일한 message만 표시한다. history는 configured maximum entry 수로 제한한다.

## Configuration Boundary

Unity client config에는 server IP, TCP/UDP port, shared-data manifest의 absolute path가 필요하다. World presentation database, actor presentation catalog, camera/movement profile 조합도 유효해야 startup을 진행한다. 이 값들은 scene/prefab 설정이며 server content를 Unity에서 직접 소유하지 않는다.
