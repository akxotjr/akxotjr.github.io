## Metric Catalog

이 문서는 `MetricsAggregator`가 출력하는 metric key의 참조표다. 모든 scalar는 별도 표기가 없으면 metrics window 내 `Sum`으로 집계한다. `Latest`는 metrics window 종료 시점의 현재값, `Maximum`은 metrics window 안의 최고값이며, histogram은 HDR HLOG에 기록된다.

| Scope | 소유 범위 | Source ID |
| --- | --- | --- |
| `process` | process 전체 | logical core metric에서는 core index |
| `executor_global` | Global Executor | 없음 |
| `executor_shard` | Shard Executor | `shardIndex` |
| `network_shard` | shard-local network state | `shardIndex` |
| `network_process` | 모든 shard network state의 process 집계 | 없음 |
| `simulation_world`, `aoi_world`, `replication_world` | World simulation state | `shardIndex`, `worldId` |

## Process Metrics

| Metric key | Aggregation | 의미 |
| --- | --- | --- |
| `process_cpu_usage` | Latest | process CPU 사용률 |
| `working_set_bytes`, `private_bytes` | Latest | process memory 사용량 |
| `core_cpu_usage` | Latest | logical core별 CPU 사용률 |

## Executor Metrics

### Global Executor

| Metric key | 의미 |
| --- | --- |
| `worker_loop_count`, `worker_jobs_executed`, `worker_idle_loop_count` | offload worker loop, 실행 job, idle loop 수 |
| `worker_wait_ns`, `worker_job_execution_ns` | worker wait 및 job 실행 시간 |
| `fiber_loop_count`, `fiber_poll_count`, `fiber_empty_poll_count` | fiber worker loop, poll, empty poll 수 |
| `fiber_poll_ns`, `fiber_sleep_ns` | fiber poll 및 sleep 시간 |
| `fiber_ready_runs` | ready continuation 실행 수 |

| `mailbox_ready_wait_sample_count`, `mailbox_ready_wait_ns` | Sum | ready mailbox wait 표본 수와 누적 대기 시간 |

| `jobs_executed`, `process_jobs_call_count` | Sum | 실행 job 수와 process-jobs 호출 수 |

| `local_critical_peak`, `local_control_peak`, `local_background_peak`, `local_total_peak` | Maximum | priority별 및 전체 local queue 최고값 |
| `ingress_moved_per_loop_max`, `mailbox_moved_per_loop_max`, `jobs_executed_per_loop_max` | Maximum | loop당 ingress, mailbox, 실행 job의 최고 이동량 |

## Network Metrics

`network_shard`는 shard별 값을, `network_process`는 모든 shard의 합계를 기록한다. `network_process`에서 current/peak 계열도 process 총량을 보기 위해 `Sum`으로 집계된다.

| Metric key | Shard aggregation | 의미 |
| --- | --- | --- |
| `tx_bytes`, `rx_bytes`, `tx_packets`, `rx_packets` | Sum | 전체 송수신 byte와 packet 수 |
| `udp_tx_bytes`, `udp_rx_bytes`, `udp_tx_packets`, `udp_rx_packets` | Sum | UDP 송수신 byte와 packet 수 |
| `reliable_original_bytes`, `reliable_original_packets` | Sum | 최초 reliable 전송량 |
| `reliable_acked_bytes`, `reliable_acked_packets` | Sum | ACK 확인된 reliable 전송량 |
| `rtx_bytes`, `rtx_packets`, `rtx_recovered_packets`, `rtx_timeout_packets`, `rtx_giveup_packets` | Sum | retransmission 및 복구·timeout·포기 상태 |
| `out_of_order_packets`, `duplicate_packets` | Sum | out-of-order와 duplicate packet 수 |
| `ack_standalone_packets`, `ack_piggybacked_packets` | Sum | standalone 및 piggyback ACK 수 |
| `pending_reliable_current`, `active_sessions` | Latest | pending reliable 및 active session 현재값 |
| `pending_reliable_peak`, `max_rtx_per_packet` | Maximum | pending reliable 및 packet별 retransmission 최고값 |

## World Metrics

### Simulation

| Metric key | Aggregation | 의미 |
| --- | --- | --- |
| `tick_duration_overflow`, `tick_overrun_count` | Sum | tick duration histogram overflow 및 tick budget 초과 수 |
| `participants_current`, `users_current` | Latest | participant 및 user 현재 수 |
| `participants_peak` | Maximum | participant 최고 수 |
| `tick_duration`, `input_duration`, `physics_duration`, `aoi_duration`, `replication_duration`, `finalize_duration` | HDR Histogram | 전체 tick 및 phase별 duration 분포 |

### AOI

| Metric key | Aggregation | 의미 |
| --- | --- | --- |
| `neighbors_per_user_overflow` | Sum | AOI neighbor histogram 범위 초과 수 |
| `entered_actors`, `left_actors` | Sum | AOI enter 및 leave actor 수 |
| `neighbors_per_user` | HDR Histogram | user별 visible neighbor 수 분포 |

### Replication

| Metric key | Aggregation | 의미 |
| --- | --- | --- |
| `snapshot_packets`, `snapshot_chunks`, `snapshot_bytes`, `snapshot_actors` | Sum | snapshot packet, chunk, byte, actor 수 |
| `snapshot_full_actors`, `snapshot_delta_actors` | Sum | full state 및 delta state로 encode된 snapshot actor 수 |
| `lifecycle_packets`, `lifecycle_bytes`, `lifecycle_events`, `lifecycle_packet_splits` | Sum | lifecycle 전송량, event, packet split 수 |
| `lifecycle_pending_current` | Latest | lifecycle pending 현재값 |
| `lifecycle_pending_peak` | Maximum | lifecycle pending 최고값 |
| `baseline_resends`, `baseline_full_requests`, `baseline_resyncs` | Sum | baseline 재전송, full 요청, resync 수 |
