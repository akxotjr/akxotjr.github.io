게임 서버와 실시간 멀티플레이 시스템을 설계하고 구현한 과정을 기록합니다.

단순한 기능 소개보다는 **어떤 문제를 발견했고, 시스템의 경계를 어떻게 나누었으며, 어떤 선택과 검증을 거쳐 해결했는지**를 중심으로 정리합니다.

## Projects

### Jam

[[Projects/Jam/index|Jam]]은  C++ 기반의 멀티플레이 게임 서버 프레임워크입니다.

서버 권위형 월드 시뮬레이션을 중심으로 네트워크 세션, shard 기반 실행 모델, AOI와 상태 복제, 물리 연동, Unity 클라이언트 연결을 하나의 일관된 런타임으로 구성하고 있습니다. 기능을 추가하는 데 그치지 않고, 소유권과 실행 위치, 비동기 작업의 수명, 장애 상황에서의 복구처럼 실제 서버 구조에서 중요해지는 문제를 설계 대상으로 다룹니다.

주요 주제:

- shard 기반 병렬 실행과 명시적인 실행 소유권
- UDP reliability와 세션 수명 관리
- 서버 권위형 월드, AOI, replication
- PhysX 시뮬레이션과 스케줄링
- C++ 런타임과 Unity 프런트엔드의 경계
- 스키마 기반 Shared Data와 코드 생성 파이프라인

### M1

[[Projects/M1/index|M1]]은 [[Projects/Jam/index|Jam]]을 실제 콘텐츠 환경에서 검증하기 위한 소규모 MMORPG 샘플 프로젝트입니다.

로그인과 캐릭터 선택부터 월드 입장, 이동 동기화, 포탈을 통한 월드 전환, 채팅으로 이어지는 기본 플레이 흐름을 구현하고 있습니다. 서버 권위형 이동과 다중 클라이언트 상태 복제를 실제 콘텐츠 위에서 검증하며, 단일 서버 프로세스 기준 **1,000 CCU**를 목표로 반복 가능한 부하 시나리오와 측정 기준도 함께 설계합니다.

현재 주요 범위:

- 계정 인증과 캐릭터 선택
- 월드 입장·퇴장 및 포탈 이동
- 서버 권위형 캐릭터 이동
- AOI 기반 상태 복제
- Global, Group, Personal 채팅
- 봇 클라이언트와 성능 검증 시나리오
- 인벤토리, 개인 거래, 거래소를 위한 데이터 모델
